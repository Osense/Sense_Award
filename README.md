# 쎈스 어워드 (Sense Award)

엑셀 명단을 붙여 넣으면 상장 용지에 맞춰 상장을 한꺼번에 만드는 웹앱입니다. **WSNS studio** [웨스엔에스 스튜디오]

- 서비스: https://osense.github.io/Sense_Award/
- 모든 처리는 브라우저 안에서만 이루어지며 명단·도장 이미지는 서버로 보내지 않습니다.

## 기능

단계마다 화면 전체를 쓰는 전용 페이지로 진행합니다.

1. **용지** — 견본 용지(금색 테두리 시판 기본형 · 전통 문양 · 단정한 이중선 · 가로형 감사장)를 지금 명단의 실제 모습으로 크게 보여 줍니다. 고르면 글 상자 배치가 그 용지에 맞게 바뀝니다. 내 상장 용지를 스캔해 올려 쓸 수도 있습니다. 견본 테두리는 화면에서만 보이고 인쇄에는 들어가지 않습니다.
2. **명단** — 엑셀에서 복사해 붙여 넣으면 첫 줄이 변수 이름(키)이 됩니다. 넓은 표에서 바로 고치거나, 미리보기를 보며 한 장씩 입력할 수 있습니다. 문구의 변수가 명단에 없으면 비슷한 항목을 찾아 이어 줍니다.
3. **문구·배치** — 한글·오피스·캔바처럼 화면 위 리본에서 고칩니다. 상자를 누르면 리본에 그 칸의 글꼴·크기·굵게·색, 글자 가로 정렬(왼쪽·가운데·오른쪽·양쪽·균등)과 세로 정렬, 줄 간격·최대 줄, 자동 맞춤 한계, 배치(용지 기준 정렬·위치·크기), 도장이 나옵니다. 칸을 고르지 않고 글꼴을 바꾸면 모든 칸에 적용됩니다. 상자를 두 번 누르면 그 자리에서 문구를 고치고 변수를 넣습니다. 상자를 끌면 용지 가운데·안쪽 여백·다른 상자에 가이드 선과 함께 붙습니다(Alt를 누르면 자유 이동). 방향키 0.5mm·Shift 5mm 이동.
4. **확인·내보내기** — 상장 목록에서 한 장씩 확인하고, 미리보기의 글자를 누르면 **그 상장만** 내용을 직접 고칠 수 있습니다(원래 문구로 되돌리기 가능). PDF(미리보기와 동일) / 한글 HWPX(글상자)로 내보내고, 프린터 위치 보정(mm)을 넣을 수 있습니다.

#### 확대·축소
Ctrl(⌘)+마우스 휠이나 트랙패드 핀치로 마우스 자리를 기준으로 확대·축소합니다. Ctrl + / Ctrl − / Ctrl 0(맞춤), 미리보기 위 −·+·맞춤 단추도 있습니다.

### 자동 맞춤
글이 상자보다 길면 **장평 → 자간 → (줄 수 한도 안에서 어절 단위 줄 나눔) → 글자 크기** 순서로 줄입니다. 칸마다 최소 장평·최소 자간·최소 크기·최대 줄 수를 정할 수 있습니다. 미리보기·PDF·HWPX가 같은 배치 결과(줄·글자 좌표)를 씁니다.

## 글꼴
기본 글꼴은 조선궁서체입니다. 나눔명조·고운바탕·나눔고딕·고운돋움도 고를 수 있습니다. 라이선스는 `site/fonts/print/README.md` 참고.

## 구조

```
site/                 GitHub Pages로 배포되는 정적 사이트
  js/layout.js        글자 맞춤 엔진(장평·자간·크기·어절 줄 나눔)
  js/render.js        한 장 배치 계산 + 미리보기 SVG
  js/export-pdf.js    PDF (pdf-lib + fontkit, 글꼴 서브셋 임베드)
  js/export-hwpx.js   HWPX (OWPML 글상자, JSZip)
  js/papers.js        견본 용지와 용지별 기본 배치
  hwpx-template/      HWPX 기본 골격
tools/smoke.mjs       노드에서 배치·PDF·HWPX 생성 점검 (npm test)
```

로컬 실행: `npm run serve` 후 http://localhost:8765
