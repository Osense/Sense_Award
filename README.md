# 쎈스 어워드 (Sense Award)

엑셀 명단을 붙여 넣으면 상장 용지에 맞춰 상장을 한꺼번에 만드는 웹앱입니다. **WSNS studio** [웨스엔에스 스튜디오]

- 서비스: https://osense.github.io/Sense_Award/
- 모든 처리는 브라우저 안에서만 이루어지며 명단·도장 이미지는 서버로 보내지 않습니다.

## 기능

열면 늘 **프로젝트 목록**(처음 화면)에서 시작합니다. 상장 묶음마다 프로젝트를 만들고, 이름 바꾸기·복제·삭제를 합니다. 프로젝트마다 용지·명단·문구·배치·도장이 이 기기(브라우저)에 따로 저장되고, 새 프로젝트는 늘 견본 상태에서 시작합니다. 머리글의 "쎈스 어워드" 글자를 누르면 프로젝트 목록으로, WSNS 로고를 누르면 WSNS studio 홈페이지로 갑니다. 프로젝트를 열면 단계마다 화면 전체를 쓰는 전용 페이지로 진행합니다. 되돌리기·다시 하기: Ctrl+Z / Ctrl+Shift+Z(또는 Ctrl+Y), 머리글 단추.

1. **용지** — 시판 보통 상장 용지(A4, 금색 이중 테두리) 하나를 기본으로 씁니다. 테두리는 벡터로 그리며 위치·선 두께·간격·모서리 오목한 크기·색과 글 영역 여백을 수치로 미세 조정합니다. 항목마다 "기본값" 단추, 위쪽에 "견본 디자인으로 전체 초기화" 단추가 있습니다. 모서리 장식은 기본으로 꺼져 있고, 켜면 종류(덩굴·꽃·잎·점)와 크기를 고릅니다. 글 영역을 줄이면 글 상자의 자리와 크기만 함께 오므라들고(직접 옮긴 상자도 같은 비율로), 글자 크기는 견본 용지 기준 그대로입니다. 좁아진 상자에 글이 다 들어가지 않으면 자동 맞춤이 장평 → 자간 → 크기 순으로 줄입니다. 이 테두리가 다음 단계의 배경이 되고 인쇄에는 들어가지 않습니다(빈 종이 인쇄용으로 넣기 선택 가능).
2. **명단** — 엑셀처럼 쓰는 표입니다(아래 "명단 표"). 첫 줄(항목 줄)이 변수 이름(키)이 됩니다. 미리보기를 보며 한 장씩 입력할 수도 있습니다. 문구의 변수가 명단에 없으면 비슷한 항목을 찾아 이어 줍니다.
3. **문구·배치** — 글 상자는 **자동 배치**됩니다(아래). 화면 위 리본에서 칸의 글꼴·크기·굵게·색, 글자 정렬, 줄 간격·최대 줄, 자동 맞춤 한계, 배치, 도장을 고칩니다. 상자를 두 번 누르면 그 자리에서 문구를 고칩니다. 상자를 끌면 가이드 선과 함께 붙습니다(Alt로 자유 이동). 직접 옮기거나 크기를 바꾼 칸은 "직접 배치"로 고정되고, "자동으로"·"전체 자동"으로 되돌립니다.
4. **확인·내보내기** — 상장 목록에서 한 장씩 확인하고, 미리보기 글자를 누르면 그 상장만 내용을 고칩니다. PDF / 한글 HWPX로 내보냅니다.

### 자동 배치(상장 디자인 규칙)
실제 상장·표창장 4종을 **테두리 안쪽 틀 기준**으로 재어 세로 리듬을 정했습니다. (용지 전체 비율을 글 영역에 넣으면 수여자가 바닥 테두리에 붙어 답답해집니다.)

| 요소 | 견본 용지 자리(mm, 가운데) | 크기 |
|---|---|---|
| 상장번호 | 윗선 33 · 본문 왼쪽 끝 | 본문의 0.66배, 12~14.5pt |
| 제목 | 64 | 글 영역 너비의 11%(약 45pt). 2자는 자간을 넓게, 4자 이상은 좁게 |
| 소속 / 이름 | 이름 99, 소속은 바로 위 · 오른쪽 끝 | 이름 본문의 1.12배(17pt 이상), 소속 0.92배 |
| 본문 | 116부터 날짜 위까지 | 칸을 채우는 가장 큰 크기(13~24pt) |
| 날짜 | 205 | 본문 비슷하게(수여자의 85% 이하) |
| 수여자 | 234 | 본문의 1.25배(18pt 이상), 제목의 62% 이하 |

- 위 여백(틀 → 제목 윗선)과 아래 여백(수여자 → 틀)이 약 36mm로 맞물려 무게중심이 광학 중심에 옵니다. 글 영역 아래 12mm는 늘 비워 둡니다.
- 본문이 짧아 최대 크기에 걸리면 남는 공간의 40%만큼 본문을 내려 위아래 숨을 맞춥니다. 아주 길면 본문 시작을 이름 바로 아래로 올립니다.
- 수여자가 두 줄(직함 / 이름)이면 칸을 키우고 날짜를 위로 밀어 간격을 지킵니다.
- 글자 크기는 상장 한 장마다 그 장의 글 길이로 정하고, 다른 항목도 본문 크기를 따라 커지고 작아집니다. 크기 위계: 본문 ≤ 이름 ≤ 수여자 ≤ 제목.
- 이 자리는 글 영역 비율로 바꿔 쓰므로 1단계에서 테두리·여백을 바꾸면 상자만 따라 움직이고 글자 크기는 그대로입니다.

### 양식: 한국 상장 · 미국식 증서
처음 화면에서 양식을 골라 새 프로젝트를 만듭니다. 양식마다 칸 구성·견본 명단·테두리·처음 넣어 둘 마크 프레임이 다릅니다.

**미국식 증서(Certificate of Recognition)** — 미국 주 하원·주 상원·시·연방 하원·단체 증서 5종에서 뽑은 공통 문법을 따릅니다.

| 순서 | 칸 | 서체 | 규칙 |
|---|---|---|---|
| 1 | 문장(마크 프레임, 원형) | — | 맨 위 가운데 |
| 2 | 발행처 | Cormorant Garamond 굵게 | 대문자·넓은 자간(45%), 9~13pt |
| 3 | 증서명 | Pinyon Script(필기체) | 한 줄에 드는 가장 큰 크기 22~46pt, 아래 금색 이중선 |
| 4 | 수여 문구 | Cormorant 기울임 | "This certificate is proudly presented to" |
| 5 | 이름 | Pinyon Script | 가장 크게(20~42pt), 밑줄 |
| 6 | 소속·직함 | Cormorant 굵은 기울임 | 10~16pt |
| 7 | 본문 | Cormorant 기울임 | 가운데 정렬, 칸을 채우는 크기 11~17.5pt, 짧으면 남는 공간 가운데로 |
| 8 | 날짜 | Cormorant 기울임 | "Presented this 21st day of November, 2026", 오른쪽 기둥 |
| 9 | 서명선·서명자 | Cormorant 굵게 | 서명선 위 12mm는 손 서명 자리, 이름 / 직함 두세 줄 |
| 10 | 인장(마크 프레임, 원형) | — | 왼쪽 아래, 날짜·서명 기둥과 짝 |
| 11 | 서명(마크 프레임, 사각) | — | 서명선 바로 위. 견본 서명 그림이 들어 있고 눌러서 내 서명으로 바꿈 |

위에서부터 앞 칸 아랫선 + 간격으로 쌓아 어떤 길이의 글이 들어와도 겹치지 않습니다. 테두리(가는 금색 이중선)는 빈 종이 인쇄를 전제로 기본으로 함께 인쇄합니다. 한글이 들어가면 나눔명조로 대신 그립니다.

### 마크 프레임(캔바의 프레임처럼)
- 3단계 리본의 "마크"에서 원형·사각·둥근 사각 틀을 넣습니다. 미국식 증서에는 문장·인장 틀과 견본 서명이 든 서명 틀이 미리 들어 있습니다.
- 한국 상장에는 도장 틀이 미리 켜져 있습니다. 관례대로 수여자 마지막 음절(끝 글자)의 절반을 덮게 놓입니다(도장 왼쪽 끝 = 끝 글자 가운데, 세로는 글줄 가운데). 점선 사각을 누르면 도장 그림을 고릅니다(장마다 수여자를 따라 움직임).
- **배경 지우기**: 휴대폰으로 찍은 JPG 도장도 종이를 투명하게 만들고 인주만 남깁니다. 그림을 칸으로 나눠 칸마다 종이색(밝은 쪽 92~98%)을 잡아 그림자·누런 종이를 고르게 편 뒤, 잉크 농도로 투명도를 정하고(부드러운 가장자리), 잉크 색을 되살리고, 작은 얼룩을 지우고 여백을 잘라 냅니다. '지우는 정도'로 문턱을 조절합니다. 이미 투명한 PNG는 그대로 씁니다. 마크 틀(로고·인장)에도 같은 기능이 있습니다(원본은 보관해 껐다 켤 수 있음).
- 빈 틀은 모든 단계의 화면에 점선으로 보이고, 출력에는 들어가지 않습니다.
- 빈 틀을 누르면 그림을 고릅니다. 그림은 틀을 늘 덮도록(cover) 들어가고, 투명 PNG(로고·인장)는 투명 그대로 씁니다.
- 그림이 든 틀을 두 번 누르면 자르기: 틀 밖 그림이 흐리게 보이고, 끌어서 옮기고 휠(또는 확대 막대 100~600%)로 키웁니다. Esc로 끝냅니다.
- 틀은 끌어 옮기고 모서리로 크기를 바꿉니다(원형은 늘 정원, 사각은 Shift로 비율 유지). 방향키 0.5mm(Shift 5mm), Delete로 지우기, 되돌리기 지원.
- 출력(PDF·바로 인쇄·한글)에는 그림이 든 틀만, 틀 모양으로 잘라 낸 300dpi PNG로 들어갑니다(틀 밖 투명).

### 오른쪽 클릭 메뉴
3단계(문구·배치)에서 누른 대상에 맞는 메뉴가 뜹니다. 4단계(확인)에서는 글자를 오른쪽 클릭해 그 상장만 고칩니다.
- **글 칸**: 문구 고치기(모든 상장), 변수 넣기 ▸ {{상장명}}·{{이름}}…(커서 자리에 넣음), 이 상장만 고치기 / 되돌리기, 글자 정렬 ▸, 상자 위치 ▸, 자동 배치로 되돌리기, 글자 서식 복사 / 붙여넣기
- **여러 칸**: 맞추기 ▸(왼쪽·가로 가운데·오른쪽·위·세로 가운데·아래), 묶음째 가운데로, 간격 같게, 글자 정렬, 서식 붙여넣기
- **마크 틀**: 그림 넣기/바꾸기, 틀 안에서 자르기, 맞춤 처음대로, 배경 지우기, 모양 ▸, 복제, 맨 앞/맨 뒤, 그림 빼기, 틀 지우기
- **도장**: 도장 넣기/바꾸기, 배경 지우기, 붉은색으로 맞추기, 자리 처음대로, 도장 빼기 / 쓰지 않기
- **빈 곳**: 여기에 틀 넣기 ▸, 도장 틀 넣기, 모든 칸 고르기, 전체 자동 배치, 칸 테두리·가이드 맞춤 켜고 끄기, 화면에 맞추기
- 모든 메뉴 아래에 되돌리기·다시 하기. Esc나 바깥을 누르면 닫힙니다.

### 명단 표(엑셀처럼)
- 칸을 누르고 Ctrl+V: 엑셀·한셀·구글 시트에서 복사한 범위가 그 칸부터 들어갑니다. 넘치면 줄·항목이 자동으로 늘어납니다. 칸 안 줄바꿈(따옴표로 묶인 값)도 그대로 옵니다.
- 항목 줄 첫 칸(A)에 붙여 넣으면 제목 줄 포함 표 전체를 바꿉니다. 데이터 칸에 붙여 넣을 때 제목 줄이 딸려 오면 건너뜁니다. 값 하나를 범위에 붙이면 범위 전체를 채웁니다.
- 칸을 고른 채 바로 타자를 치면 입력, F2·두 번 누르기로 고치기, Alt+Enter 칸 안 줄바꿈, Ctrl+Enter 고른 범위 모두 채우기, Esc 취소.
- 방향키·Tab·Enter 이동, Shift로 범위 넓히기, Ctrl+방향키 끝으로, Delete 지우기, Ctrl+C/X 복사·잘라내기(엑셀로 다시 붙여 넣기 가능), Ctrl+Z/Y 되돌리기.
- 채우기 핸들(선택 오른쪽 아래 점)을 끌면 끝 숫자가 늘어납니다(2000-1771 → 2000-1772…, 자리 수 유지). Ctrl을 누르고 끌면 그대로 복사.
- 칸 맨 앞 공백은 지우지 않습니다. 상장에서는 공백 하나를 한 칸(한글 한 글자 너비)으로 보고 문단 첫 줄을 들여씁니다(원고지의 첫 칸 띄우기). 견본 본문도 첫 칸을 띄워 두었습니다.
- 화면은 고정되고 표 안에서만 스크롤됩니다(머리 줄·항목 이름은 붙박이).
- 열 경계를 끌어 너비를 줄이거나 늘리고, 두 번 누르면 내용에 맞춰 되돌립니다.
- 오른쪽 클릭: 줄·항목 넣기/지우기, 잘라내기·복사·붙여넣기, 내용 지우기. 항목 이름을 바꾸면 문구의 변수도 함께 바뀝니다. 열 경계를 끌어 너비 조절.

### 상자 다루기
- 여러 상자 고르기: Shift·Ctrl(⌘)+누르기, 빈 곳을 끌어 사각형으로 고르기, Ctrl+A.
- 고른 상자들은 함께 끌고 방향키로 함께 옮깁니다. 리본 서식(글꼴·크기·정렬 등)도 모두에 적용됩니다.
- 끌 때 Shift: 많이 움직인 쪽(가로/세로)으로만 움직입니다. Alt: 가이드 맞춤 잠시 끄기.
- 배치 팝업: 하나면 글 영역 기준 정렬, 여럿이면 고른 상자끼리 정렬(왼쪽·가운데·오른쪽·위·가운데·아래), 묶음째 용지 가로 가운데로, 세로·가로 간격 같게(3개 이상).

### 바로 인쇄
4단계 "바로 인쇄"는 미리보기와 같은 글자 윤곽을 A4 실제 크기 페이지로 펼쳐 브라우저 인쇄 창으로 보냅니다(용지 A4·여백 0을 인쇄 창에 미리 알려 줌). 배율·위치 보정이 그대로 들어가고, PDF와 위치가 같습니다. 인쇄 창에서는 배율 기본값(100%), 여백 없음, 머리글·바닥글 끄기. 시험 인쇄도 "시험 인쇄 바로 하기"로 같은 경로를 거쳐야 보정값이 정확합니다.

### 인쇄 배율 문제 대응
- PDF는 A4 실제 크기이며, 인쇄 창 기본값이 "실제 크기(100%)"가 되도록 PDF 보기 설정(PrintScaling=None, 용지 크기로 급지)을 넣습니다. "용지에 맞춤"으로 인쇄하면 3~6% 줄어 상장 칸과 어긋나므로 화면에서도 안내합니다.
- 글 상자가 가장자리에서 얼마나 떨어져 있는지 계산해 5mm보다 가까우면 경고합니다(프린터가 못 찍는 여백).
- 맞춤 확인용 시험 인쇄 PDF: 100mm 가로·세로 자, 글 영역 모서리 십자, 테두리 윤곽. 빈 종이에 인쇄해 상장 용지와 겹쳐 봅니다.
- 보정: 100mm 선 실측값으로 배율 보정(용지 가운데 기준), 가로·세로 위치 보정(mm). PDF와 HWPX 모두에 적용됩니다.
- PDF 글꼴은 HarfBuzz(hb-subset)로 쓴 글자만 남겨 넣습니다(pdf-lib 서브셋은 일부 한글 글꼴에서 글자가 빠짐).

### 확대·축소
Ctrl(⌘)+마우스 휠이나 트랙패드 핀치로 마우스 자리를 기준으로 확대·축소합니다. Ctrl + / Ctrl − / Ctrl 0(맞춤), 미리보기 위 −·+·맞춤 단추도 있습니다.

### 자동 맞춤
글이 상자보다 길면 **장평 → 자간 → (줄 수 한도 안에서 어절 단위 줄 나눔) → 글자 크기** 순서로 줄입니다. 칸마다 최소 장평·최소 자간·최소 크기·최대 줄 수를 정할 수 있습니다. 미리보기·PDF·HWPX가 같은 배치 결과(줄·글자 좌표)를 씁니다.

## 글꼴
기본 글꼴은 조선궁서체입니다. 나눔명조·고운바탕·나눔고딕·고운돋움도 고를 수 있습니다. 미국식 증서용 영문 서체로 Pinyon Script(필기체), Cormorant Garamond(보통·굵게·기울임), UnifrakturMaguntia(고딕 장식체)를 넣었습니다(모두 SIL OFL 1.1, fonts/print에 라이선스 동봉). HWPX를 한글에서 같은 모양으로 열도록 4단계 "한글에서 열 때" 상자에서 쓴 글꼴의 TTF를 바로 내려받습니다(조선궁서체는 배포 WOFF의 포장만 푼 TTF — 글꼴 표는 원본과 같음, 배포 형태 그대로 쓰는 조건 준수). 라이선스는 `site/fonts/print/README.md` 참고.
